AI Content Styler (Telegram Mini App) — Единое ТЗ v1.3 [CANONICAL]
Last Updated: 2025-12-15

1) Цель
- Создать TMA для SMM-специалистов: генерация/перепись постов для Instagram и Threads с управляемой тональностью через Style Sliders, с жёсткими правилами длины и форматирования.

2) Архитектура и стек
- Платформа: Telegram Mini App (Web App).
- Frontend: React (или Vue 3) + TailwindCSS + shadcn/ui.
- Backend: Python (FastAPI) или Node.js (Hono/Express).
- Database: PostgreSQL (профили, пресеты) или Redis (кэш сессий).
- LLM: OpenAI (GPT-4o/mini) или Anthropic.
- Hosting: Vercel (frontend) + Railway/VPS (backend).

3) Функциональные требования (MVP)
3.1 Ввод данных
- Текстовое поле (textarea) для черновика, плейсхолдер: «О чем пишем сегодня?».
- Переключатель платформы: Instagram | Threads.
- Кнопка «Сгенерировать» фиксирована снизу.

3.2 Style Sliders
- Defaults: Краткость 50, Креативность 50, Сарказм 20, Контроверсия 10, Юмор 0.
- Safety Caps: режим B2B — Сарказм ≤30, Юмор ≤40; режим «Эссе» — Краткость авто 20–30; при выкручивании всего на 100% — предупреждение и усреднение параметров.
- Advanced: слайдер «Юмор» скрыт по умолчанию, открывается кнопкой «Дополнительно».

3.3 Генерация и вывод
- Streaming вывода (эффект печати).
- Действия: Copy, Save Preset, Regenerate; для Threads — «Копировать всё» и копирование по частям.

4) Формат и длина (Acceptance)
- Threads: каждая часть ≤500 символов, пронумерована `1/X`, `2/X`; авто-сплит по смыслу и длине, без хэштегов внутри частей; 0–2 эмодзи на часть (только если Креативность >20).
- Instagram: хук в первой строке, 2–5 абзацев по смыслу, CTA перед блоком хэштегов, хэштеги 5–10 в конце одним блоком; эмодзи допустимы в хук/CTA/поддержку эмоций, не в каждом предложении; лимит 2 200, предупреждение после 1 800.
- Абзацы: каждая новая мысль — новый параграф (`\n\n`), избегать «стен текста».
- Чистота: тримминг, без двойных пробелов, без ALL CAPS; сохраняем язык исходника, если не запрошено иное.
- Читабельность: средняя длина предложения ≤160 символов; при Brevity >80 — ≤90. Для B2B — избегать жаргона и шуток выше caps.
- Regenerate: сохраняет структуру (абзацы/CTA/нумерацию), меняет лексику и углы.

5) Валидация и модерация
- Фронт: счётчик символов и подсветка остатка; блокирует отправку при пустом тексте или невыбранной платформе; предупреждение/запрет при переполнении (Threads >500 на часть, Instagram >2 200).
- Бэк: повторная проверка лимитов и структуры; при нарушении — либо авто-починка без изменения смысла, либо ошибка с подсказкой.
- Модерация: pre-/post-check на токсичность/prompt injection; поддержка детекта языка; таймауты и обработка ошибок с подсказкой retry.

6) Backend/API
- Endpoint `/generate` принимает JSON со всеми полями (платформа, текст, sliders, режимы).
- Параметры LLM: `llmTier` = fast | quality (fast → gpt-4o-mini, quality → gpt-4o), `responseLanguage` = auto | ru | en (auto: если вход RU и нет явного запроса EN → RU; при явном запросе EN → EN).
- Формирование system prompt:
  - Краткость >80 → «Be extremadamente concise, use bullet points».
  - Сарказм >50 → «Use witty irony».
  - Threads → «Split text into tweets of 500 chars max, numbered 1/X».
  - Instagram → «Add hook title, paragraphs, and 5-10 hashtags at the end».
  - Дополнительно: инструкции по абзацам/CTA/эмодзи/триммингу/языку (см. раздел 4).
- Streaming Response (SSE или fetch stream) с возможностью отмены; формат ответа и коды ошибок документированы.
