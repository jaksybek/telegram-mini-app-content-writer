# Scripts
Last Updated: 2025-11-20

## Files
- `md_to_pptx.py` — [CANONICAL] CLI tool that transforms Markdown outlines into PPTX decks with optional speaker notes by parsing headings, bullets, and blockquotes.

## Usage
- Run `python3 scripts/md_to_pptx.py <source.md> <output.pptx>` to convert any Markdown file (output argument optional).
- Example: `python3 scripts/md_to_pptx.py PROJECTS/Pitchdeck/PLAN.md PROJECTS/Pitchdeck/PLAN_auto.pptx` regenerates a deck that mirrors the pitch plan ([REF: PROJECTS/Pitchdeck/PLAN.md#slide-outline-working]).
